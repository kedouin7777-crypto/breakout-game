# ブロック崩し

Canvas製のブロック崩しゲームです。`breakout.html` をブラウザで開くだけで遊べます。

## 遊び方
- ← → / A D : パドル移動
- Space / クリック : 発射
- P : 一時停止 / M : サウンド切替

## 特徴
- 4ステージ（ボール速度が段階的に上昇）
- スコア・ライフ・コンボ倍率
- パワーアップ: M 多重球 / W ワイドパドル / S スロー / + 残り1UP
- ★ ボーナスブロック（高得点・ドロップ確定）
- ■ 鋼ブロック（3回必要・ステージ2以降）

## ファイル
- `breakout.html` : ゲーム本体
- `breakout-deploy/` : Cloudflare Pages公開用コピー
